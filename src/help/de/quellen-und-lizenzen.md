# Quellen und Lizenzen

Das Studio nutzt öffentlich verfügbare Daten. Wer eine Karte veröffentlicht, muss die Quellen angeben. Die Bedingungen der Anbieter gelten, diese Seite ersetzt sie nicht.

| Daten | Anbieter | Nutzung im Studio |
|---|---|---|
| Karten, Gewässer, Wälder, Orte, Industrien | © OpenStreetMap-Mitwirkende (ODbL) | Overpass-Abfragen, Kartenanzeige |
| Höhen weltweit | Copernicus DEM (ESA/EU), bereitgestellt über AWS | Quelle „Copernicus“ und Schnellvorschau |
| Höhen Deutschland | Landesvermessungen (DGM1), Abruf über hoehendaten.de | Quelle „DGM1“ |
| Höhen Schweiz | swisstopo, swissALTI3D | Quelle „swissALTI3D“ |
| Höhen Niederlande | AHN über PDOK | Quelle „AHN“ |
| Höhen Österreich | BEV, ALS DTM Höhenraster 1 m (CC BY 4.0) | Quelle „BEV Österreich“, siehe [Österreich](help:oesterreich-bev) |
| Höhen Luxemburg | ACT, Lidar 2024, MNT (CC0 1.0) | Quelle „Luxemburg MNT 2024“, siehe [Luxemburg](help:luxemburg-mnt) |
| Schattenrelief | AWS Terrain Tiles | Karte + Relief |

## Angabe bei einer Veröffentlichung

*Beschreibung zum Teilen…* im Heightmap-Dialog erzeugt einen Text mit der Höhenquelle, ihrer Quellenangabe und den Änderungen an den Höhendaten. Kopiere ihn in deine Karten-Beschreibung (zum Beispiel auf Steam). Nenne außerdem OpenStreetMap, wenn du Gewässer, Biome, Städte oder Industrien daraus erzeugt hast: **© OpenStreetMap-Mitwirkende**.

Ausführliche Angaben je Quelle stehen im Heightmap-Dialog unter **F1**.
