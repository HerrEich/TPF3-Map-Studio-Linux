# TPF3 Map Studio v0.7.0

Biome und Höhenskala in der 3D-Vorschau, Gelände sanft um Seen mitsenken, ein Biome-Fenster, das nicht mehr blockiert, weniger Speicherverbrauch beim OSM-Download und die neue Höhenquelle Luxemburg MNT 2024. / Biomes and a height scale in the 3D preview, terrain gently lowered around lakes, a Biome window that no longer blocks, less memory use during the OSM download, and the new height source Luxembourg MNT 2024.

## Deutsch

Neu
- 3D-Vorschau: Biome werden angezeigt, dazu eine Höhenskala mit Beschriftungen und eine Legende.
- Gelände sanft um Seen mitsenken: Das Gelände rund um einen See wird weich abgesenkt, statt eine harte Kante zu lassen.
- Höhenquelle Luxemburg MNT 2024. Im Studio getestet, im Spiel noch nicht.

Verbessert
- Das Biome-Fenster blockiert das Studio nicht mehr, du kannst nebenher weiterarbeiten.
- Der OSM-Download braucht deutlich weniger Arbeitsspeicher.

Installation: `TPF3-Map-Studio-v0.7.0-win64.zip` herunterladen, die ganze ZIP entpacken, `TPF3-Map-Studio.exe` starten. Windows warnt beim ersten Start eventuell („Weitere Informationen“ -> „Trotzdem ausführen“), bei PyInstaller-Programmen sind Virenscanner-Fehlalarme bekannt.

SHA-256: `7a7130e2fea8d9ffc248f0c72204a49db5ee703c77f891de96d7cb42e02cd5a8`

Hinweis: inoffizielles Werkzeug, keine Verbindung zu Urban Games.

## English

New
- 3D preview: biomes are shown, plus a height scale with labels and a legend.
- Terrain gently lowered around lakes: the terrain around a lake is lowered smoothly instead of leaving a hard edge.
- Height source Luxembourg MNT 2024. Tested in the Studio, not in the game yet.

Improved
- The Biome window no longer blocks the Studio; you can keep working while it is open.
- The OSM download uses much less memory.

Install: download `TPF3-Map-Studio-v0.7.0-win64.zip`, extract the whole ZIP, run `TPF3-Map-Studio.exe`. Windows may warn on first start ("More info" -> "Run anyway"); antivirus false positives are known for PyInstaller programs.

SHA-256: `7a7130e2fea8d9ffc248f0c72204a49db5ee703c77f891de96d7cb42e02cd5a8`
